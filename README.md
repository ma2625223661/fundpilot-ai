# FundPilot AI · 板块研究

默认启用账号密码登录。首次在运行后台的电脑上打开网站，请自行创建管理员账号和密码；之后必须登录才能访问研究页面、报告接口和个人数据。没有预设或通用密码。其他用户可注册自己的账号，关注列表与研究记录按账号分别保存。

支持可配置的注册手机号验证、已有账号绑定和短信验证码登录。默认未启用短信，账号密码注册与登录继续可用；短信启用后默认要求新用户验证手机号。开通配置与接口见 [手机号验证说明](docs/phone-verification.md)。

管理员在本机仍可管理已有的 Windows 加密模型配置，已有市场报告与计划继续使用。手机通过同一局域网地址访问时也需要登录。云端入口与本机入口分开；本机登录保护不代表已经部署到公网。

网站只研究行业、主题、宽基指数、海外市场、风格和资产方向。后台采集板块参考指数、日线历史、市场指数、行业成分、公司财务、公开上市公司公告和官方政策，计算趋势、波动、回撤及板块研究指数，保留数据来源和时间。

基金列表、基金净值、基金持仓、基金公告、基金筛选和指定基金研究已从运行流程移除。板块没有直接数据时保留方向，未知项显示 `*****`，不使用基金表现或相关板块代替。

## 启动与使用

双击 `start.cmd`，或在本项目运行 `E:\python\python.exe launch.py`。启动器会打开 `http://127.0.0.1:8765/index.html`；重复启动会识别并复用现有网站，与当前选择的 AI 服务商无关。服务运行时后台持续更新；关闭网页不会停止研究，服务退出或电脑关闭后停止。其他程序占用端口时保留原程序，可用 `start.cmd --port 8876` 另选端口。

- 板块总览支持分组、搜索、推荐指数和当日涨幅排序；点击方向查看理由、反对证据、风险、复核条件、行情依据和相关事件。
- 推荐指数使用深红至深绿的分档颜色，是固定规则的观察排序工具，不是未来上涨概率。缺失或失效数据不生成当前指数。
- “数据与依据”展示板块行情、市场指数、免费行业与公司财务接口、公开公告与官方政策来源。采集时间与数据本身的时间分别显示。
- 未配置或关闭 DeepSeek 时继续运行板块量化研究；配置并验证后，按保存的时间计划调用 AI 解读已有证据。AI 不能补造数据或更改确定性分数。
- 当前 AI 计划为 A 股交易日北京时间 09:20、14:50 各一次，周末及已核验节假日跳过。电脑及服务须保持运行，错过时段不补跑。也可在设置中改为按间隔、每日固定时间或每日时段循环。
- 保存计划保留原开关；只改时间不会立即调用模型。预约状态在发出付费请求前持久化，重启不重复占用已预约时段。
- 浏览器只保存最多 20 份板块报告。旧基金观察池、个人约束、偏好及报告缓存在新版页面启动时清除，不会转成板块报告。

## 数据范围

- 东方财富公开行业/概念板块报价与日线序列；只有明确对应的参考系列才能进入该板块分析。
- 腾讯财经公开市场及基准指数；海外时间需按对应市场时区解释。
- 行业成分与财务默认使用无需 Token 的 BaoStock；免费接口覆盖有限，行业样本不能冒充经完整市值/业务比较核验的龙头，接口未取数成功时明确显示未知。
- 消息只采用巨潮公开上市公司公告、国家发改委官方政策及证监会监管发布。正文未取得的消息不作事件影响评分；不采用普通媒体新闻补造事件。
- 涨跌家数只描述取得的板块成分样本，不是全市场或基金涨跌分布。
- 只有直接报价时显示短期观察，历史不足会限制推荐指数；报告过期则当前指数变为未知。
- 公开接口可能失效或部分不可达，板块数量不代表所有方向已接入完整行情。

## 事件与信号

事件影响分由经营影响40%、覆盖25%、持续性20%、证据明确程度15%加权；每维0–5，换算0–100。只显示绝对值至少40分的中等及以上事件，按绝对值从高到低排序。利好用绿色正分，利空用红色负分；双向影响单独标注。每条保留来源、发布时间、事实节选、传导理由和维度分。

深红叹号是有明确条件的特大风险提示：公开事件为至少90分利空且经营影响/证据至少4、覆盖至少3；或有效板块日跌幅至少5%，或完整历史下20日跌幅至少10%且窗口回撤至少25%。资料不足和普通高风险不会触发。深绿星要求完整历史、研究指数至少75、5日与20日收益及20日均线差均为正，且未触发高风险；事件星号还要求至少70分利好并关联这样的板块。上述分数与符号均为研究规则，不代表收益概率。

## 后台与存储

- `research_sectors.py`：直接板块采集、分类映射、历史指标、研究指数与市场风险。
- `research_sector_ai.py`：逐板块 AI 理由、风险、复核条件、证据约束与真实用量。
- `research_auto.py`：板块模式调度，跳过全部基金研究和分类流程。
- `server.py`：运行板块模式，原 `/api/research` 和 `/api/analyze` 返回 410。
- `dist/sector-research.js`、`dist/sector-research.css`：新版页面，不再载入旧基金界面 `app.js`。
- `data/sector-report.json`：最新板块报告；`data/sector-report.schedule.json`：AI 预约状态。
- `data/deepseek-config.dpapi.json`：当前 Windows 用户 DPAPI 加密配置，密钥不回传浏览器。

切换时，原基金清单和基金报告退出活动存储，移入本机 `backups/before-sector-only-*`，不再被网站加载。纯日程状态迁移以保留预约，原 API 配置保留。

## 自建龙头样本指标

`research_leader_index.py` 为具备明确公司归属、有效行情的行业/风格/宽基方向独立编制等权指标，不再依赖官方板块报价才能评分。当前官方成分内按总市值最多选3家领先样本；半导体材料设备采用已核对的931743成分名单。此筛选不认证主营市占率龙头。仅对这些样本追加腾讯前复权日线，不扩大财务研究公司范围。

共同历史首日100；每日等权平均样本收益再连乘。历史固定为本轮样本回溯，换样后重算，不拼接旧组合。至少2只、全部选定样本共同近期61个交易日才评分；不足时展示已取得的真实数据及缺口。盘中报价与已完成日线分开，不混用不同交易日或过期报价。综合分由趋势规则、已披露业绩调整、已评估官方重要事件调整组成，并受大盘风险上限约束。未经收益回测，不是收益概率。没有公司归属的方向继续显示缺口，不随意指定公司或伪造指标。

详情展示独立点位、样本名单与权重、回溯走势，并可展开“龙头走势、业绩支撑、重要事件、大盘风险、综合研究分数”查看日期、公式及来源。消息评分仍仅用公开公告/官方政策，按A股交易日09:20和14:50计划运行；普通更新不额外强制付费调用。债券保留独立债券模型，不使用股票样本指标。

验证：`python -m unittest test_research_leader_index`；`node --test test_leader_index_frontend.cjs test_sector_frontend.cjs test_event_frontend.cjs`。

## 手机访问

电脑与手机连接同一可信局域网，用电脑的局域网 IPv4 地址和端口 8765 访问。`127.0.0.1` 只指当前设备；电脑和 Python 服务需保持运行。


## 2026-10-31 独立样本指标扩展

- 以明确官方成分或公司官网业务证据建立样本，每方向核验至多12家候选，选取至多8家数据完整公司。通常保留4家市值/固定池代表，其余按已披露盈利及增长条件补充；微盘方向在完整国证A股成分池内按小市值选样。归属、报价、披露日财务及近期61个交易日任一不完整的候选单列说明；公开业务池不称完整板块名单或认证市占率龙头。
- 存储芯片同时核对国证产业指数成员与公司存储业务，避免宽产业链设备公司仅因市值高而占据全部样本。
- 公司日线先用腾讯前复权数据；沪深返回失败或近期缺日时，整段切换BaoStock前复权日线。北交所备用采用新浪同代码日线及前复权因子，核对证券身份及收盘后整段转换；保留价格、因子、身份三个来源，不拼接供应商价格，也不猜测旧证券代码。
- 港股、美股使用独立代表公司样本、各自交易日历和本地收盘时间；美股处理纽约夏令时。只用当地已完成交易日。海外2026交易日历未核验的其他年份停止生成当前分数，须补齐该年交易日历后使用。
- 港股未取得复权序列时会标明未复权价格样本及公司行为风险。未取得真实财务披露日期的数据只作参考，不计入业绩调整。海外板块大盘风险采用全站A股风险约束，明确不代表当地市场风险。
- BaoStock连接检查改为行业、日线、财务三项独立受限进程，各自验证真实样本、日期和接口返回；一项超时不阻止其他两项核验。小样本连通性成功不代表所有板块数据完整。未登录错误仅重新连接复查一次，不通过修改显示状态掩盖失败。
- 海外缓存独立保存并限制4MB，SEC只保存财务计算与溯源所需字段，避免原始大文件让国内缓存重启后无法读取。官方完整成分另存最后成功解析的工作簿快照，校验身份、名单日期与文件摘要；源站失败时保留本次错误及原日期。
- 官方完整成分不可取得时，可沿用先前报告中已核验官方归属的固定公司样本，单独保存为有限样本池，最长按原名单日期核验45天。页面明确未取得本轮完整名单、不作本轮全成分市值排名。固定样本、完整成分与公开业务证据分别标注；备用归属不能替代对当前报价、财务与共同历史的独立核验。
- 公司综合研究分数、仅参考指数走势分数、债券/转债专用分数和资金利率分数分别标注范围；缺少公司证据时不把参考走势分包装为公司综合分。样本与生产核验结果见 `docs/company-sample-pools-20261031.md`，复核入口 `work/verify_audit_live.py`。
