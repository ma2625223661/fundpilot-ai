# 免费研究数据的持续更新与恢复

2026-11-02 修复了午休行情按自然时间重复判过期、业务核验队列导致后续板块整批跳过，以及完整采集覆盖旧证据的问题。

- 行情有效期统一由交易日历判断，午休保留上午最新观测；采集中收到的新报价按接收时间核验。
- 业务证据优先读有效缓存，网络任务交错分配到各板块。网络失败可沿用 45 天内先前核验的原文，保留原核验日期；事实校验失败不能借旧原文通过。
- 原始财务、完整前复权日线及公司证据分别持久保存。仅恢复同证券、原始日期仍合格的证据；恢复后重新计算指标，不复制旧评分。
- 部分盘中报价缺失时，仅在所有样本都有最新已收盘交易日的完整日线时，整组切换为收盘口径。页面标明收盘日期，不能把隔夜涨跌展示为当前盘中涨跌。
- 成分来源明确移除的公司不会通过后续缓存恢复。财务披露日、45 天归属窗口及最近 61 个当地交易日仍逐项核验。
- 当日快速更新会每隔至少 15 分钟重试缺失的公司方向；重复更新按来源 ID 去重，避免报告不断膨胀。

主要代码为 `research_evidence_resilience.py`、`research_public_data.py`、`research_theme_memberships.py`、`research_leader_index.py` 和 `research_sectors.py`。持久证据位于 `data/public-company-cache.json`，需要与研究报告一起保留。新模块使用标准 Python 库，不需要付费 AI 请求。

回归验证：`E:\python\python.exe work\data-resilience-20261102\run_regressions.py`。此脚本隔离测试缓存，不将模拟证据写入正在使用的数据目录。

外部来源持续中断或原始证据超过有效期时仍须如实显示缺口，不生成虚构行情、财务或完整评分。
