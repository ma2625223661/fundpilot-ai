# 五个交易日复盘

入口为“研究记录”顶部“AI 自动化复盘”。围绕登录账号的关注列表展示。管理员及有效、未暂停的订阅均可使用，研究点数用完不影响订阅期内的附带复盘；过期、暂停、未订阅不可取得复盘内容。

公司走势复盘分由 `research_review.price_review` 根据本轮公司样本的连续26个已收盘交易日计算。其中6个收盘点形成5个区间，前20个收益测量期前波动。五日趋势、相对表现、回撤控制、上涨持续性各25分。A股参照本站沪深300公司样本（非官方指数），港股和美股分别参照同日期的恒生、标普500价格指数，使用当地已核验交易日历。公式与零波动处理在页面口径说明中显示。当前样本回溯存在选样偏差；分数衡量历史路径，不是上涨概率或预测命中率。

没有公司样本、但有准确映射日线的方向，使用独立价格观察模型：趋势40、回撤35、持续性25，不补造公司相对分，也不把缺失项折算成100分。日本、印度、越南、欧洲和多市场参考按来源实际发布的26个收盘观测计算，明确提示当地完整休市日历未核验，不宣称日期连续。欧洲来源未返回币种时，只使用已核验身份的指数点位变化，保留币种缺失提示，不做汇率或金额换算。

货币方向使用61个隔夜Shibor发布值的专用流动性模型，展示年化利率与5、20次发布的基点变化，不展示股票收益、回撤或买入推荐，不安排该方向的额外AI复盘请求。卡片“复盘依据”可展开查看样本、来源、日期与复权口径。港股原始未复权行情会标明除权除息跳变风险。

原始研究另存 `review_journal`，同板块同基准日仅保存第一条真实观测，保存180天。稍后取得的首份完整评分另存不可覆盖的 `review_decisions`，核验时优先使用这份实际完成的判断，保留初始阶段记录。不会通过导入旧报告倒填当时记录。当地盘中记录的判断以当日收盘为基点，不把已经发生的当日涨跌纳入后续结果。五个后续交易日完成后，使用冻结名单内所有公司的同一复权口径序列，计算等权日收益及回撤；已明确标注未复权的样本保留相同口径及跳变提醒。参考指数与利率须保持相同来源身份与单位。换样、缺股、缺日期或复权口径改变均等待补齐。原始评分不完整时继续明确标注，不改写为完整研究判断。环境风险变化是当前时点对照，不冒充历史期末风险。

`GET /api/me/reviews` 只读取本地报告与账号权限，不调用供应商、不扣点、不接收其他用户id。内部行情必须与报告 `as_of` 一致，公开报告接口不暴露原始历史集合。未登录返回401，未订阅返回无内容的锁定状态。普通历史报告最多20份，与复核留档独立。

公开采集失败时，公司仅可沿用仍覆盖最新已收盘交易日的原始日收盘报价；盘中价格不作为收盘缓存，移出名单的公司不补回。参考指数、组合与利率只整组复用原来源及历史，重新检查当地日期与身份，不拼接两个来源。缓存保留原日期与来源，并标注本轮更新未齐；新交易日过期后继续待补数据。多市场组合的独立输入历史也保留在内部报告，避免重启丢失已核验观测。

AI通过 `research_personal_ai.personalized_runner` 接入，遵守已有A股交易日09:20/14:50窗口。每轮最多一批8个关注方向复盘，先处理一批复盘再处理公共板块解读，全部共享原有每日请求和Token上限，不抬高预算。同一证据、模型和推理深度的有效解读持久复用；失败使用同一证据缓存的30分钟冷却，不自动重试。中度和极高文本独立生成，但复盘本身不扣用户点数。服务商实际调用仍计入管理员费用账本，聚合到 `ai_research`，另列 `five_day_review` 子项。认证或余额错误立即阻止本轮其他付费请求。

AI只解释可核验输入，必须引用本板块来源；无效来源、重复板块、截断响应、模型擅自回传分数均不发布。既有复盘经验可进入后续板块AI解读的证据，用于改进核验条件；不自动修改主评分权重，也不宣称已经提升预测准确率。
