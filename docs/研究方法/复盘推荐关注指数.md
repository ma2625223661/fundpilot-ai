# 复盘推荐关注指数

本功能由有效订阅附带提供，不扣研究点数。刷新只读取本地数据；AI 解读继续使用 A 股交易日北京时间 09:20、14:50 的既有计划与预算保护，最多一批 8 个。

## 三种口径分开显示

- 公司研究分：现有基本面、走势和事件研究，不修改其算法或档位。
- 五日走势复盘分：公司样本仍为四项各25分，港股与美股使用当地参照和交易日。只有来源指数时使用独立的40/35/25价格模型；货币利率另用流动性观察模型。
- 推荐关注指数：以完整五日复盘分为起点，用当前研究和风险条件设置上限，反映研究关注优先级。

指数取五日复盘分与所有适用上限中的最小值，上限不会重复相减。65 及以上为乐观看待，50 至不足 65 为中性，30 至不足 50 为谨慎，低于 30 为规避。

| 条件 | 上限 |
| --- | --- |
| 完整公司研究满足重点跟踪门槛 | 100 |
| 公司研究为中性 | 64 |
| 公司研究为谨慎，或完整研究尚未形成 | 49 |
| 公司研究为规避 | 29 |
| 环境风险未评估或达到 70 | 49 |
| 环境风险达到 85 | 29 |
| 行情高风险 / 特大风险 | 49 / 29 |
| 五日最大回撤达到 10% | 29 |
| 五日收益为负或落后参考公司样本 | 64 |

完整五日评分、参考数据或有效报告缺失时，指数为待评估，不补成 0 分，也不把基础研究分 /70 折算为完整 /100。该上限策略是明确的筛选政策，未经收益策略回测，不是上涨概率。

仅有价格指数的方向即使历史价格观察分较高，仍受公司研究未完整的49分上限约束，不会据价格上涨推断财务或事件。货币方向单列“流动性观察指数”，仅说明隔夜资金松紧；它不表示产品回报、安全性或投资推荐。海外方向的中国环境风险明确只是环境参照，不替代当地市场或汇率风险。

## 操作参考

页面分别展示：尚未参与如何观察、已经持有时如何复核、升档/维持条件、降级和风险条件，以及带当前值的核验清单。没有用户的持仓、成本、产品报价和风险偏好，因此不编造个性化买卖价或仓位比例。

AI 在定时研究中补充条件式操作思路，必须引用输入证据，不能提供或修改数值指数，也不能提升输入允许的行动档位。当前免费数据更新造成的风险变严时，过于积极的旧 AI 操作思路会被隐藏，历史解读仍可回看；新规则指数不触发额外 AI 调用。

两个推荐数据与 AI 证据缓存分开：盘中风险及研究上限变化更新当前规则建议；AI 复盘缓存仅随五日证据、原始核验结论、推理深度或提示格式变化。非订阅者、暂停或过期账号不返回复盘及建议内容。
