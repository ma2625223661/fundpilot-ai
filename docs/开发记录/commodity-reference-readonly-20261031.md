官网当前脚本中明确使用 `/CCI-ZZZS`，真实只读请求：

```text
GET http://www.ccidx.com/CCI-ZZZS/indexDetails/getDateLineByIndexIds
  ?mainIndexId=100001.CCI
  &indexIds=100001.CCI,000001.CCI
  &timeRange=1年
  &startTime=2025-10-30
  &endTime=2026-10-30
```

2026-10-31 05:20北京时间实测 HTTP 200，JSON `code=20000`、`success=true`。两代码各243个唯一交易日，2025-10-30至2026-10-30，收盘点位全部为正值。返回默认按日期倒序，计算前必须按交易日升序排序。原始证据保存在：

- `work/commodity-official-identity-check-20261031.json`

字段必须区分：`closingPrice` / `preClosingPrice` / `dailyIncreaseAndDecreasePercentageClose` 是收盘口径；`settlePrice` / `preSettlePrice` / `dailyIncreaseAndDecreasePercentage` 是结算口径。不要把通用涨跌字段误当收盘涨跌，也不要把归一化点位 `closingPriceNorm` 当原始点位。

交易日历请求 `GET /CCI-ZZZS/indexDetails/getTradingCalendar?indexId=100001.CCI` 也实际成功。该接口时间为带时区的UTC序列，转北京时间后取交易日，不能直接切前10个字符。

## 商品指标的适用范围与未知

如果后续选用该口径，可以基于同一代码、同一收盘或结算口径的真实历史计算趋势、动量、波动和回撤，并明确这是商品期货价格或超额收益序列研究。它不能直接沿用上市公司“龙头走势、业绩支撑”的完整五项模型。

以下尚未取得，必须保留未知或不适用，不能由股票公司财报替代：

- 当前合约构成、合约权重及换月安排；
- 现货价格、期限结构、升贴水及展期收益分解；
- 库存、仓单、持仓量和成交量；
- 保证金、抵押资产利息、交易成本与实际可投资收益；
- 全收益指数身份及同口径历史；
- 正式生产访问与再分发授权。

公司财务在商品期货模型中应标为“不适用”，上述未取得的商品基本面应标为“未接入”。只取得历史价格时可以给出价格趋势分，但不应宣称完整商品基本面综合评分。
