# 板块列表颜色与排序修复（2026-10-31）

原先页面将所有 company_research_v2 的阶段分强制传入未知色，导致已经取得基本面与走势的方向全部显示灰色；六段旧色阶也不符合用户确认的四档门槛。默认排序还将参考走势0分排在公司阶段49分之前。

现在统一采用四段颜色：

| 分值区间 | 颜色 | 完整公司研究档位 |
| --- | --- | --- |
| ≥65 | 绿色 | 乐观看待，仍须基本面≥28与其余已批准门槛全部通过 |
| ≥50且<65 | 黄色 | 中性 |
| ≥30且<50 | 橙色 | 谨慎 |
| <30 | 红色 | 规避 |

完整公司分若≥65但乐观门槛未通过，沿用中性档及黄色。基础/阶段分使用当前原始数值区间着色，保留pending状态和实际缺项；基础/70不放大为/100，也不因此获得完整档位。未知分数与历史报告保持灰色。

默认按公司完整分、公司基础分、公司阶段分、参考走势、转债、债券、资金利率、待补数据分别排序；只在相同口径内部比较数值。列表直接展示基本面/40、走势/30、事件的实际评估状态，区分行情风险与环境风险。正负事件继续分别使用绿、红文字；特大风险符号不受阶段颜色影响。
