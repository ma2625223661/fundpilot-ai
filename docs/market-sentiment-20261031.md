# 市场情绪指数

板块研究首页新增独立的0～100分市场情绪卡，显示样本活跃程度。它不进入公司研究分、事件影响分或环境风险分，也不代表收益概率。

| 分项 | 权重 | 计算 |
| --- | --- | --- |
| 样本上涨广度 | 40% | 100 ×（上涨家数＋0.5 × 平盘家数）/ 有效去重A股数 |
| 四大指数强弱 | 30% | clip（50＋有效指数平均涨跌幅 × 10，0，100） |
| 样本MA20参与度 | 30% | 100 ×（前复权收盘高于20日均线家数＋0.5 × 相等家数）/ 有效历史样本数 |

指数白名单为上证综指、深证成指、沪深300、创业板指。公司样本来自现有研究池，按证券代码跨板块去重；港股、美股、债券与资金利率不进入公司样本。公司研究池经过筛选，不能当作全市场涨跌家数。

广度和MA20各至少20家有效公司，指数分项至少2个指数。至少两项有效且可用分项权重达到70%才生成总分。缺项不填中性值，按可用权重归一，并显示部分数据及缺口；权重覆盖率不表示全市场证券覆盖率。指数只有2/4或3/4时也显示部分数据。

同一证券优先取最新有效报价；同一时点数值冲突则剔除该证券的广度数据。历史采用截至最近完整交易日的连续20个交易日前复权收盘，不把盘中未复权价格与复权均线比较；历史冲突剔除该证券的MA数据。报价与历史分别显示日期。休市期按已核验交易日历接受最近完整收盘，未知日历不假定有效。

| 分数 | 状态 |
| --- | --- |
| 0～<20 | 低迷 |
| 20～<40 | 偏冷 |
| 40～<60 | 平稳 |
| 60～<80 | 活跃 |
| 80～100 | 过热 |

上述为固定观察规则，未经过收益回测。高分只表示参与度活跃；过热意味着拥挤风险值得关注，不表示买入信号。走势与广度存在相关性，不能当成独立证据相乘。

后端纯计算模块为 `research_market_sentiment.py`。新报告生成时写入 `market_sentiment`；旧报告在公共视图缓存生成时补算，原始证据不变，摘要心跳不触发计算。历史或过期报告清空当前总分及分项分数，页面明确标注待更新。前端只接受白名单字段与有限数值，以文本节点展示来源内容。

沿用现有板块报告更新流程与A股交易日09:10、14:30计划。此指标不新增数据请求或AI模型调用。页面支持桌面及手机宽度，可展开分项、完整公式、范围、缺口和来源。

验证包括纯计算边界、去重/冲突、交易日时效、缺项归一、公共视图缓存与原始报告隔离、前端过滤/档位/仪表状态，以及独立无界面浏览器的桌面和手机布局检查。
