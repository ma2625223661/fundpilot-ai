BaoStock 备用日线调用：

```python
query_history_k_data_plus(code, 'date,code,close', start, end,
                          frequency='d', adjustflag='2')
```

`adjustflag='2'` 为前复权。备用会替换整条公司日线，不拼接不同数据源的价格。每个批次运行在独立子进程中，有硬超时，并保留实际来源及获取时间。
