# 手机访问

先在 Windows 电脑手动启动网站，再让手机与电脑连接到同一可互通的局域网。

在电脑进入“模型与数据设置”，选择右上角“手机访问”，复制卡片中的地址到手机浏览器。
地址由当前电脑的实际网络地址生成；更换 Wi-Fi 或 IP 变化后重新复制。
`127.0.0.1` 在手机上指手机自身，不能用它连接电脑。

电脑需保持开机，网站启动窗口保持运行。此项目保留手动启动方式。
手机可浏览研究、数据依据及研究记录；浏览器记录按设备独立保存。
API 密钥、计划保存和数据源取数检查由运行服务的电脑管理，局域网访问仅显示其状态。

若打不开，依次检查后台窗口、手机和电脑所在网络、Windows 防火墙程序许可，
以及路由器的访客网络/设备隔离。项目未配置公网托管。

界面在 360、390、650、768、900、1074、1440、1920 像素宽度检查过四个视图，
验证了页面宽度、导航触摸区域、手机详情与局域网配置限制；尚未进行实体手机测试。
