# 市场流动性指数

市场概览新增独立的“市场流动性指数”。它沿用货币市场的人民币隔夜 Shibor 专用模型，分数越高表示观察到的资金利率相对平稳或趋宽；这与环境风险分的方向不同，环境风险分越高表示风险越大。

当前报告（数据日 **2026年10月30日**）显示：

- 市场流动性指数：**53/100，中性**
- 环境风险中的流动性风险：**47/100**
- 隔夜年化利率：**1.289%**
- 资金趋势：**资金趋宽**
- 有效历史观测：**121个发布日**

模型沿用货币市场流动性观察模型：基准50分，结合5/20/60个有效发布日的利率变化、20日利率波动和当日资金收紧情况计算。页面同时展示1日、5日、20日基点变化和数据时间。

指数只观察人民币隔夜资金利率，不代表股票收益、存款安全、货币基金收益或完整资金供给。缺少有效利率历史时显示“数据待补充”，过期报告显示“待更新”，不填中性分。
