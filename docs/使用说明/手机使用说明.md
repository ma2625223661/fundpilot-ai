# 手机访问

网站**默认只允许运行它的这台电脑访问**。局域网连接使用未加密的 HTTP，同一 Wi-Fi 中的人可能看到登录密码和会话，所以手机访问需要手动开启。

## 开启手机访问

1. 只在可信的家庭或办公网络中开启。
2. 用下面任一方式启动网站：
   - 运行 `start.cmd --allow-lan`；
   - 或先设置环境变量 `FUNDPILOT_ALLOW_LAN=1`，再双击 `start.cmd` 或 `启动网站.vbs`。
3. 让手机与电脑连接到同一个可互通的局域网。
4. 在电脑上打开“设置 → 订阅帮助与手机访问”，复制“手机访问网址”到手机浏览器。地址由电脑当前的网络地址生成；更换 Wi-Fi 或 IP 变化后重新复制。

不再需要时，去掉 `--allow-lan`（或该环境变量）重新启动，就恢复为仅本机访问。需要更安全的远程访问，请通过 HTTPS 反向代理提供服务，不要把 HTTP 端口直接暴露到公网。

`127.0.0.1` 在手机上指手机自身，不能用它连接电脑。

## 手机上能做什么

电脑需保持开机，网站后台保持运行。手机可浏览研究、数据依据及研究记录，管理自己的关注和密码。

API 密钥、研究计划、数据源检查等公共设置只能由管理员在运行网站的电脑上修改。即使是管理员账号，通过手机或局域网访问时，设置页也只显示状态，并提示到电脑上修改。

## 打不开时

依次检查：网站是否用 `--allow-lan` 启动、后台是否仍在运行、手机和电脑是否在同一网络、Windows 防火墙是否允许该程序，以及路由器的访客网络或设备隔离。

界面在 360、390、650、768、900、1074、1440、1920 像素宽度检查过各个视图；尚未进行实体手机测试。
